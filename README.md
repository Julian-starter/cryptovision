## ⚡ Cryptovision

CryptoVision es una Single Page Application (SPA) diseñada como una terminal avanzada de inteligencia cripto y simulación de flujos institucionales.

ESTE PROYECTO FUE HECHO PARA FINES ACADEMICOS, NO CUENTA CON UN SISTEMA DE PAGO Y SOLO CONTIENE INFORMACIÓN EN TIEMPO REAL RELACIONADO A LOS BLOCKCHAINS.

## Caracteristicas

* Enrutamiento virtual sin recarga del DOM utilizando React 19.
* Motor visual de seguimiento de nodos y billeteras.
* Matriz de lectura de WebSockets para detectar spreads entre exchanges.
* Análisis on-chain, auditoría de seguridad y tokenomics.
* Análisis contextual impulsado por la API de Google Gemini.

## Stack

* React, Vite.
* Tailwind CSS v4, Framer motion
* Recharts
* Capacitor JS

##  Instalación Local
1. Clona el repositorio: `git clone https://github.com/TU-USUARIO/cryptovision-terminal.git`
2. Instala las dependencias: `npm install`
3. Crea un archivo `.env` en la raíz y añade tus API Keys:
   `VITE_GEMINI_API_KEY="tu_api_key"`
4. Inicia el servidor de desarrollo: `npm run dev`
